## 摘要
视觉-语言模型通常将预训练视觉编码器生成的所有token投影到大型语言模型中。然而，最终层特征可能丢弃文本、局部属性和空间关系，而高分辨率输入会显著增加上下文长度和推理延迟。我们提出\method，一种多尺度自适应视觉编码器。\method使用位置依赖门控融合视觉Transformer的浅层、中间和深层特征，在保留全局语义的同时增强边缘、文本和局部结构。随后，根据问题相关性、局部信息含量、全局语义和空间覆盖进行问题条件化的token路由，token预算根据图像复杂度自适应。为减轻压缩损失，我们进一步引入全量到压缩表示蒸馏和空间多样性正则化。在一个统一的7B语言模型框架下的模拟实验中，\method将SigLIP-SO400M视觉token的平均数量从729个减少到146个（约80.0%），并在VQAv2、GQA、TextVQA、ScienceQA-IMG和MMBench上的平均得分提升2.2个百分点，同时将单图像首token时间从228毫秒降至129毫秒。我们提供了完整的模型设计和评估协议。当前所有报告的数字仅作为论文组织和实验设计的占位符；正式结论需要实际训练运行、独立复现和官方基准评估。

## Abstract
Vision-language models commonly project all tokens produced by a pretrained vision encoder into a large language model. However, final-layer features can discard text, local attributes, and spatial relationships, while high-resolution inputs substantially increase context length and inference latency. We introduce \method, a Multi-scale Adaptive Vision Encoder. \method uses position-dependent gates to fuse shallow, intermediate, and deep features from a vision Transformer, preserving global semantics while enhancing edges, text, and local structure. It then performs question-conditioned token routing according to question relevance, local information content, global semantics, and spatial coverage, with a token budget that adapts to image complexity. To mitigate compression loss, we further introduce full-to-compressed representation distillation and a spatial diversity regularizer. In an illustrative simulation under a unified 7B language-model framework, \method reduces the average number of SigLIP-SO400M visual tokens from 729 to 146 (approximately 80.0\%) and improves the mean score on VQAv2, GQA, TextVQA, ScienceQA-IMG, and MMBench by 2.2 percentage points, while reducing single-image time to first token from 228\,ms to 129\,ms. We provide the full model design and evaluation protocol. All reported numbers currently serve only as placeholders for paper organization and experimental design; formal claims require real training runs, independent replications, and official benchmark evaluation.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有的视觉-语言模型（VLM）通常只使用视觉编码器最后一层的所有 token 投影到语言模型。这导致两个主要缺陷：
  - 最后一层特征侧重于全局语义，丢失了边缘、纹理、文字笔画、局部属性和空间关系等细粒度信息（例如影响OCR、计数、局部属性识别）。
  - 为提升细粒度感知而采用高分辨率输入（如448×448）会使 token 数量激增（约4倍），显著增加上下文长度和推理延迟（TTFT）。
- **动机**：需要一种既能保留细粒度多尺度信息，又能自适应压缩视觉 token 数量，从而在保持甚至提升性能的同时加快推理速度的视觉编码方案。
- **整体含义**：论文提出 MAViE（多尺度自适应视觉编码器），旨在同时解决“细粒度表示不足”和“视觉token冗余”两个问题，为多模态模型提供高效、可扩展的视觉前端。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 利用视觉Transformer中不同层的互补特性：浅层（边缘、纹理）→ 中间层（部件、区域结构）→ 深层（全局语义）。
- 通过位置依赖门控融合多尺度特征，再根据问题（question）动态选择最相关的视觉 token，同时将未选中的 token 压缩为少量上下文 token。

### 主要模块

**① 层次化多级融合（HMF）**
- 从 ViT 的第8、16、24层分别提取浅层（F_s）、中间层（F_m）、深层（F_d）特征。
- 统一投影到共同维度，并对浅/中间层施加深度可分离卷积引入局部归纳偏置。
- **位置依赖门控**：每个空间位置 i 学习一个三路 softmax 门控向量，加权融合三个级别的特征，并采用残差连接（初始γ=0.1）防止浅层噪声干扰深层语义。
- **高频区域增强**：通过局部变化幅度 u_i 识别文字、边界等高频区域，在这些区域内施加局部窗口自注意力，在不增加全局注意力的前提下增强细粒度细节。

**② 问题条件自适应token路由（QATR）**
- **问题表示**：对语言模型的 token 嵌入进行注意力池化，得到问题向量 q。
- **重要性评分**：每个视觉 token i 的得分由四部分组成：
  - 问题相关性 s_rel（token与q的余弦相似度）
  - 局部信息含量 s_unc（归一化的局部变化幅度）
  - 全局语义 s_global（token与全局平均特征的余弦相似度）
  - 空间覆盖 s_cover（当前已选token集的最小空间距离，避免集中在单一区域）
- 最终得分 = λ_r s_rel + λ_u s_unc + λ_g s_global + λ_c s_cover，默认权重 (0.45,0.20,0.15,0.20)。
- **动态token预算**：通过复杂度估计器 c（基于局部变化均值/标准差、注意力熵、问题范数）将预算 K 动态设定在 [72, 288] 之间，取整为8的倍数。
- **未选token回收**：将未选中的 token 使用可学习上下文查询聚合为 M=8 个上下文 token，保留背景和布局信息。

**③ 训练目标**
- 总体损失：L = LLM + α L_align + β L_distill + η L_div，其中 (α,β,η)=(0.10,0.50,0.05)。
- LLM：标准自回归交叉熵。
- L_align：图像-文本对的 sigmoid 对齐损失。
- L_distill：全量特征与压缩后特征之间的余弦距离 + L2 距离的蒸馏损失。
- L_div：已选 token 的空间多样性正则化（高斯核距离的指数衰减）。

## 6. 主要结论与发现

- 在模拟条件下，MAViE 将视觉 token 从 729 降至 146（减少约80%），同时平均得分提升 2.2 个百分点（VQAv2 +1.4, GQA +1.5, TextVQA +3.1, ScienceQA-IMG +2.3, MMBench +2.7）。
- 首token时间从 228ms 降至 129ms（减少43.4%），内存从 17.8GB 降至 13.3GB。
- TextVQA 提升最大（+3.1），验证了层次融合对OCR和局部结构的增强。
- 组件消融表明：HMF 和 QATR 互补；蒸馏和空间多样性进一步稳定压缩。
- 动态预算可根据图像复杂度（从84到256 token）自适应分配计算资源。
- 问题条件路由在不同问题间表现出差异化的 token 选择（Jaccard相似度0.31~0.78），说明路由确实响应问题内容。
