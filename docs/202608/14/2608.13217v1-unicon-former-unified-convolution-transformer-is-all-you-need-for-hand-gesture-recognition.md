## 摘要
卷积神经网络（CNN）能高效捕捉局部特征，但由于其有限的感受野，难以处理全局上下文。另一方面，变换器通过自注意力机制有效捕捉全局依赖，但存在高冗余和计算成本高的问题。因此，为融合CNN与变换器的优势，我们提出了一种统一模型（UniCon-Former），旨在为动态手势识别提供稳健且高效的性能。该统一方法帮助模型同时学习局部和全局特征。在每个变换器阶段开始时，卷积投影有助于降低变换器块输入向量的维度。这便在各个变换器阶段形成了金字塔结构。这些特性使UniCon-Former相比传统变换器能减少资源消耗，使其在学习多尺度与高分辨率特征时更具灵活性，而这正是手势识别所需的。我们使用NVGesture和Briareo数据集进行了实验，在更少的参数和MACs条件下取得了最先进的结果。

## Abstract
Convolutional Neural Networks (CNNs) capture local features efficiently but struggle with global context due to their limited receptive field. On the other hand, transformers effectively capture global dependencies through self-attention but suffer from high redundancy and computational costs. Thus, to leverage the advantages of both CNNs and transformers, we propose a unified model (UniCon-Former) that aims to provide robust and efficient performance on dynamic hand gesture recognition. The unified approach helps the model to learn both local and global features. At the beginning of each transformer stage, the convolution projections help in decreasing the dimension of the input vectors of the transformer block. This creates a pyramidal structure at each transformer stage. These features enable the UniCon-Former to reduce resource usage than vanilla transformers, making it flexible for learning multi-scale and high-resolution features, which is required in hand gesture recognition. We have performed experiments with NVGesture and Briareo datasets and achieved state-of-the-art results with fewer parameters and MACs.

## 1. 核心问题与整体含义

动态手势识别在人机交互、游戏、虚拟/增强现实、手语识别、医疗健康等领域具有重要应用价值。在手势识别中，手部形状和大小变化多样，要求模型既能捕获局部细节，也能建模全局时序依赖。

现有方法存在明显局限：
- **CNN**：擅长高效捕获局部特征，但受限于感受野大小，难以建模全局上下文；
- **Transformer**：通过自注意力能有效建模全局依赖，但注意力机制对所有 token 进行盲目的相似度比较，导致**高冗余和高计算成本**。

论文的核心动机是：**将 CNN 与 Transformer 统一到单一框架中**，取两者之长——既保留 CNN 的局部特征提取能力，又利用 Transformer 的全局依赖建模能力——同时通过卷积投影降低计算复杂度，构建一种高效且鲁棒的动态手势识别模型。

## 2. 方法论

### 2.1 总体架构

- 输入为手势视频序列（支持 RGB、深度、红外、法向、光流等多模态）。
- 首先使用预训练的 **ResNet-18** 提取帧级特征，经过平均池化后得到维度为 `L × D` 的特征序列（L = B×T，D = 512）。
- 加入位置编码后，将特征作为 Query（Q）、Key（K）、Value（V）输入到提出的 **UniCon-Former** 中。

### 2.2 卷积变换块（Convolution Transformer Block）

核心设计：在每个 Transformer 阶段开始时，**先通过卷积块（C-Block）处理 Q、K、V 三个向量**，再送入多头注意力（MHA）模块。

C-Block 采用**深度可分离卷积**，具体结构为：
- Depth-wise Conv → BatchNorm2d → Point-wise Conv2d

公式表达为：
```
Q = Conv(F)
```
（K、V 同理）

在 C-Block 输出后添加 class token，再进入 MHA，随后经过两个线性层（FC），并加入残差连接与层归一化：
```
E(x) = Norm(x + FC(MultiHead(Q, K, V)))
```

最终将编码结果对所有帧做平均池化：
```
H(x) = AvgPool(E(x))
```
再通过线性分类器输出概率分布。

### 2.3 金字塔多尺度结构

- 每个 Transformer 阶段开始时的卷积投影会**逐步降低输入向量的维度**，从而在多个阶段形成**金字塔结构**。
- 这种结构使得模型能够分层学习**多尺度特征**，适应手部形状和大小变化，同时显著降低计算成本。

### 2.4 多模态晚期融合

- 每个模态独立训练模型；
- 测试时对不同模态的预测概率进行聚合，取最大概率对应的类别作为最终结果：
