## 摘要
机制可解释性最近已扩展到视觉Transformer（ViT），稀疏自编码器（SAE）越来越多地被用作事后工具，将内部表示分解为稀疏且更可解释的特征。然而，由于事后SAE是在ViT已经优化之后对冻结表示进行训练的，其潜在特征并不直接与下游分类目标对齐。我们引入了SpIn-ViT，这是一个联合端到端训练预训练ViT和修改后的SAE的框架，直接将稀疏的块级表示与图像分类对齐。SpIn-ViT学习语义连贯的神经元激活，这些激活定位有意义的图像区域，同时保持具有竞争力的预测性能。我们在九个图像分类基准上评估SpIn-ViT，使用分类准确率、定量可解释性指标、基于AI的评估和人工评估。与之前最先进的事后SAE方法相比，SpIn-ViT的平均分类准确率提高了8.84%，基于AI的可解释性得分提高了近四倍，人工评估得分提高了一倍以上。我们进一步使用SAE神经元提取可解释的规则集，以创建神经符号模型，这些模型在比最先进事后SAE方法创建的神经符号模型小58.8%的规则集下，平均分类准确率提高了5.97%。

## Abstract
Mechanistic interpretability has recently expanded to Vision Transformers (ViTs), with Sparse Autoencoders (SAEs) increasingly used as post-hoc tools to decompose internal representations into sparse and more interpretable features. However, because post-hoc SAEs are trained on frozen representations after the ViT has already been optimized, their latent features are not directly aligned with the downstream classification objective. We introduce SpIn-ViT, a framework that jointly trains a pretrained ViT and a modified SAE end-to-end, directly aligning sparse patch-level representations with image classification. SpIn-ViT learns semantically coherent neuron activations that localize meaningful image regions while maintaining competitive predictive performance. We evaluate SpIn-ViT across nine image-classification benchmarks using classification accuracy, quantitative interpretability metrics, AI-based and Human evaluations. Compared with the previous state-of-the-art post-hoc SAE method, SpIn-ViT achieves 8.84% higher average classification accuracy, an AI-based interpretability score nearly four times as high, and a human-evaluation score more than twice as high. We further extract interpretable rule-sets using the SAE neurons to create neurosymbolic models which achieve 5.97% higher average classification accuracy while requiring a 58.8\% smaller rule-set than the neurosymbolic models created from the SOTA post-hoc SAE method.

# SpIn-ViT 论文详细中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉 Transformer（ViT）在图像分类、检测、分割等领域表现优异，但其内部机制难以理解。具体而言，ViT 的中间表示常存在**多义性（polysemanticity）**，多个概念纠缠在同一表示中，导致神经元激活难以解释。
- **现有方法的不足**：机制可解释性领域常用稀疏自编码器（SAE）将稠密表示分解为稀疏、更接近单义（monosemantic）的特征。然而，**现有 SAE 方法大多是“事后”（post-hoc）训练的**：在 ViT 已冻结后，对冻结表示进行无监督重建。这导致两个关键问题：
  1. 潜在特征与下游分类目标不对齐，学到的稀疏特征可能视觉连贯但不具备类别判别性。
  2. ViT 通常只用 [CLS] token 微调，patch 级表示缺乏直接监督，进一步加剧可解释性困难。
- **本文核心问题**：如何让 ViT 在训练过程中直接学到**既稀疏、又可解释、且与分类目标对齐**的 patch 级表示？
- **整体意义**：本文提出 SpIn-ViT，通过**端到端联合训练 ViT 与改进的 SAE**，将稀疏表示学习与分类目标耦合，从而在高准确率的同时获得**机制可解释性**，并进一步支持符号规则提取与神经符号模型构建。

## 2. 方法论

### 2.1 总体架构

- SpIn-ViT 由三部分组成：
  1. **ViT 编码器**：输入图像 \(X \in \mathbb{R}^{C_{in}\times H\times W}\)，输出序列表示 \([z_1,\dots,z_n] \in \mathbb{R}^{n\times d}\)（\(d=768\)）。
  2. **TopK SAE 模块**：处理所有 patch token 表示，将其编码为稀疏高维潜在空间，再解码重建原始嵌入。
  3. **分类头**：使用最终 [CLS] token 输出分类 logits。
- 关键公式：
  \[
  h = \mathrm{TopK}(zW_{enc}+b_{enc}), \quad \hat{z} = hW_{dec}+b_{dec}
  \]
  其中潜在维度 \(m = 10 \times C\)（\(C\) 为类别数）。TopK 操作对每个 patch 保留最大的 k 个激活，其余置零，固定每个 patch 的活跃神经元数量。

### 2.2 学习目标（四个损失）

1. **分类损失 \(L_{cls}\)**：标准交叉熵损失，保证预测准确率，使表示与任务对齐。
2. **可解释性损失 \(L_{SAE}\)**：
   \[
   L_{SAE} = \frac{1}{B}\sum_i \|z_i - \hat{z}_i\|_F^2 + \lambda \frac{1}{B}\sum_i \|h_i\|_1
   \]
   包括重建损失（保持信息）和 L1 稀疏正则（控制激活幅度）。TopK 与 L1 互补：TopK 决定哪些神经元激活，L1 正则化激活强度。
3. **类内损失 \(L_{center}\)**（中心损失）：
   \[
   L_{center} = \frac{1}{2B}\sum_i \|p_i - c_{y_i}\|_2^2
   \]
   其中 \(p_i\) 是图像重构 patch 表示的均值池化向量，\(c_{y_i}\) 是对应类别的中心。该损失减小类内表示差异，增强类级连贯性。
4. **类间损失 \(L_{ortho}\)**（正交正则）：
   将潜在空间按类别划分为 \(C\) 个不重叠的块，每个块大小为 \(r=m/C\)，然后最小化：
   \[
   L_{ortho} = \frac{1}{C}\sum_{c=1}^{C} \left\| (S^{(c)})^\top S^{(c)} - I_r \right\|_F^2
   \]
   用于降低同一类块内潜在维度间的相关性，鼓励特征多样性、减少冗余。

**总损失**：
\[
L = \alpha L_{cls} + \beta L_{SAE} + \delta L_{center} + \gamma L_{ortho}
\]
其中 \(\alpha, \beta, \delta, \gamma \in [0,1]\) 为权重超参数。

### 2.3 可解释性量化分析流程（训练后）

1. **选择参考图像**：对每个 SAE 神经元，聚合所有 patch 激活得到全局激活向量 \(p_{patch}^{(i)} = \frac{1}{n}\sum_j h_{i,j}\)，排序并选择激活最强的 top-Kref 图像作为参考图像。
2. **Patch 分割**：推理时对潜在激活应用 Sigmoid 并阈值化（τ=0.5），得到二进制 patch 掩码，从而生成 patch 级分割图，定位神经元响应的具体区域。
3. **插入与删除（Insertion/Deletion）**：根据神经元激活对 patch 排序，计算删除相关 patch 时置信度下降幅度和插入时的上升幅度，评估神经元定位是否与模型预测依赖区域一致。

### 2.4 神经符号模型（Neurosymbolic Model）

- 将每个图像的 SAE 表示在 patch 维度上平均，经 Sigmoid 与阈值二值化，得到神经元谓词（predicate）的表格式数据。
- 使用 **FOLD-SE-M 算法**归纳得到分层 Answer Set Program（ASP）规则集，例如：
  ```
  label(X,'truck') :- neuron_63(X), not ab1(X).
  ab1(X) :- neuron_50(X), neuron_61(X).
  ```
  这类规则将分类决策表示为可读的、基于 SAE 神经元语义的逻辑条件。

## 6. 主要结论与发现

1. **分类性能**：SpIn-ViT (Ours) 平均准确率 **88.30%**，比 SOTA 事后 SAE（PatchSAE，81.13%）高 **8.84%**，且略高于 Vanilla ViT（86.56%），说明联合训练不牺牲性能。
2. **可解释性**：
   - AI 评估（mIoU 归一化到 1–5 分）：SpIn-ViT (Ours) 达到 **3.08**，接近 PatchSAE（1.27）的 **2.4 倍**；是本文宣称的“近四倍”（基于具体数值换算后可能因基准不同而有差异，但显著提升）。
   - 人工评估：SpIn-ViT (Ours) 为 **4.10**，PatchSAE 为 1.85，提升超过 2 倍。
3. **空间忠实性**：插入 AUC（0.830）最高，删除 AUC（0.142）最低，表明神经元激活区域与模型预测依赖的像素高度一致。
4. **神经符号模型**：SpIn-ViT 的 SAE 特征学得更类判别、更紧凑，用 FOLD-SE-M 提取的规则集在 9 个数据集上平均准确率 **89.34%**（高于 PatchSAE 的 84.28%），规则数量平均从 94 降至 42，缩小 **58.85%**。
5. **组件作用**：TopK 稀疏、中心损失和正交损失均对性能与可解释性有贡献；联合训练是关键，单独事后冻结（Frozen）或分开训练（Separate）都不能同时获得高准确率与高解释性。
